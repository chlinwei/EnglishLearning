## 收录词条 7：observability（读音问题）
- 用户问 `observability` 怎么读 → 重点讲发音，而非词义。
- 音标 /əbˌzɜːrvəˈbɪləti/，6 音节 ob-ser-va-BIL-i-ty，**主重音在第 4 音节 -BIL-**；常见错读是重音提前到 -SER-。
- 总结规律：**以 `-ability` 结尾的词主重音固定落在 `-BIL-`**（ability / capability / scalability / reliability / availability 全适用）。
- 注意点：**observable** 形容词重音在 -SER-，与名词不同。
- 义项补充：可观测性 = logs + metrics + traces 三大支柱，与 monitoring 有别。
- 交互约定更新进 `MEMORY.md`（整句翻译三步流程、发音讲法、配 SVG 示意图、主动收录术语）。
- 配图：observability 音节与重音拆解示意图。
