## 讲解：`clear A`（S07 · `0067` · Priya，00:19–00:27）

- 用户贴 `audio/network/0067-间歇失败` 第 4 句问「clear A 是什么意思」。
- 结论：**`clear` 的词义由宾语类型决定** —— 宾语是「东西」（cache / backlog / queue）→ **清空**；宾语是「嫌疑对象」（A / counters / the incident）→ **洗清、排除**。本句 = 一次成功查询不能给 A 洗清嫌疑。
- `A` = A 侧整套（A 区客户端 + resolver A + 走 A 的路径），**不是 DNS 的 A 记录**（最大误听方向）。
- 听感陷阱：`clear A` 连读成 «cleara»，像 `clear a ___` 冠词结构；判据是后面直接接 `right?`、没有名词。重音在 `CLEAR`。
- 逻辑层：Lukas 下一句 `A cached result could succeed while fresh requests still fail.` 才是答案——**缓存会假装健康**，成功样本不构成负证据。
- 同段对照：`0067` 第 4 句用 `clear A`、第 8 句用 `rule that out`，编稿有意做的同义对照。

## 追加：`clear` 的「放行族」（用户反馈「这个用法很新奇」）

- 用户注意到的点：`clear A` 被中译成「能证明 A」，觉得这个用法新奇。
- 讲清的统一内核：**`clear + 宾语` = 把宾语身上的「东西」拿掉，让它变成"无阻挡"** —— 容器 → 拿掉内容物 → 变空；关卡 → 拿掉障碍 → 放行；嫌疑对象 → 拿掉嫌疑 → 洗清。**动作相同，宾语类型决定拿掉什么**（与 A7 的「词义由宾语类型决定」是同一机理的两面）。
- 举的「放行族」同族词（用户其实都见过，只是没串起来）：`You're clear.`（塔台/安检）/ `clear customs`（过海关）/ **`security clearance`** / `all clear`（警报解除）/ `clear the bar`（达标）/ `clear a suspect`。**`clearance` 就是 clear 的名词形。**
- ★ 关键结论（已写进 A7）：中译「能证明 A 正常」**不是错译**，是**把结论换成了它的判据**（中文没有单个动词对应，只能借"证明"）。代价是丢了隐含前提——`clear A` 默认 **A 已在嫌疑名单上**（= 洗清、移出名单），而「证明正常」把 A 说成**中性待证**（= 验证）。**一个从嫌疑出发，一个从零出发**；这句台词的分量全在「A 现在还是嫌疑人」。
- 该结论同时**印证了 D2 的通用原则**：机器翻译对「结论/胶水义」的系统性丢译，会往"判据"上塌。
- `questions.md` A7 已增补「延伸 · `clear` 的放行族」小节（对照表 + 上述结论）。

## 追加：`blanket`（S07 · `0068` · Raj）

- 用户贴 `0068` 第 7 句 `We can rule that out as a blanket client-network failure.`，问「blanket 为什么译成整体」。
- 结论：`blanket` 作**形容词** = **覆盖全部、不加区分、一刀切**（毯子一盖全盖住）。中译「整体不可用」**不算错译，但压平了语气**——blanket 带「太粗、一刀切、没细分」的贬义，中文「整体」是中性；另外中文把 `failure` 顺手放大成了「不可用」（原文只说故障）。
- 同族：**IT 原生等义说法 = `X-wide`**（fleet-wide / cluster-wide / org-wide）、`across the board`、`total` / `complete` / `whole` / `entire`；**反义一侧** `targeted` / `scoped` / `surgical`（"别一刀切" = `keep it targeted`）。
- ★ **关键发现（已写进 A8 + §E 第 5 条）**：**同一场次内编稿刻意用不同词说同一件事** —— `0067` 说 `clear A`、同段第 8 句说 `rule that out`；`0067`→`0068` 把「整体性」从 `whole region` → `total` → `complete` → `blanket` 换了四次词；`0069` Priya 说 `fleet-wide`，`0072` 同一个 Priya 说 `blanket`。**这是复现机制，也是听力最大的陷阱：你以为在听新信息，其实是同一个信息换皮。**
- 复现统计（`dialogues.json` 已并入的 225 段）：`blanket` **4 处** = `0068` / `0072` / `0100` / `0103`；同族「整体性」**6 处** = `0067`×3 / `0069` / `0107` / `0112`。
- **交叉印证**：`0068` 里的 `rule that out` 是已登记核心表达 **`p302`**，而修饰它的 `blanket` 没登记 → 听到时只有半边有底。
